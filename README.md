# Edge-Optimized License Plate Recognition for Sri Lankan Fuel Stations Under Low-Light Conditions

## Overview
This repository contains a research project investigating INT8 quantization on YOLOv8-small for low-light license plate recognition at Sri Lankan fuel stations. The goal is to develop an edge-optimized model that balances fast inference speeds and high accuracy in challenging low-light conditions.

## Directory Structure
- `data/raw/`: Contains original, unprocessed images of license plates under low-light conditions.
- `data/processed/`: Contains preprocessed and augmented training data.
- `models/`: Stores downloaded YOLOv8 models, intermediate checkpoints, and exported quantized models.
- `scripts/`: Holds utility scripts for data preprocessing, preparation, and model evaluation.
- `requirements.txt`: Python package requirements for the project.
